# Booth Studio

展示会ブースのレイアウトをブラウザで検討する3Dシミュレーターです。日本語UI・PC向け。

## アプリを使う

**[Booth Studioを開く](https://hondatcg.github.io/booth-studio/dist/)**

インストールやログインは不要です。上のリンクをブラウザで開いて利用できます。

1. 「ブース設定」でブースの寸法と壁を設定します。
2. 「アイテム」から什器を追加し、ドラッグや右側のプロパティで配置を調整します。
3. 「マイアイテム」の「新規作成」から、手持ちの什器も登録できます。
4. 「エクスポート」からPNG・PDF・JSON形式で書き出せます。

以前のURLで作った配置を引き継ぐ場合は、以前のアプリでJSONを書き出し、このアプリの「読み込み」から取り込んでください。

## 主な機能

- ブースの幅・奥行き・高さと壁の表示設定（mm単位）
- 机、椅子、受付、棚、モニター、パネル、バナー、箱、人物の配置
- オブジェクトの移動、寸法編集、10度・90度回転、複製、削除
- 基本形状を組み合わせたマイアイテムの作成・再利用
- 真上・正面・斜め上・来場者目線への切替
- 重なり・はみ出しの警告と寸法表示
- ブラウザ内自動保存、JSON入出力、PNG・PDF出力

## エクスポート

右上の「エクスポート」からPNG・PDF・JSONを選び、保存画面の「ファイルを保存」を押してください。保存が始まらない場合は「別タブで開く」からブラウザの保存機能を利用できます。対応環境では「保存先を選ぶ」も使用できます。JSONはコピーして保存することもできます。

PDFは現在の視点・寸法をA4横の1ページに配置します。PNGとJSONのダウンロードを確認済みです。PDFは生成と描画を検証済みですが、確認用ブラウザではダウンロード完了を取得できていません。

## ファイル構成

- `dist/index.html`：画面構成
- `dist/style.css`：画面のスタイル
- `dist/app.js`：3D表示、編集、保存処理
- `dist/vendor/`：同梱のThree.jsとOrbitControls

## 保存と表示について

レイアウトとマイアイテムは、利用しているブラウザのlocalStorageに保存します。クラウド同期は行いません。別のPCで利用するときはJSONを書き出し、読み込んでください。

通常はWebGLで描画し、利用できない場合はCanvasの互換描画を使用します。互換描画では陰影・透明度・前後関係の見え方に制限があります。

重なり判定はアイテム全体を囲む直方体による目安です。実際の設営時は現物の寸法と通路幅を確認してください。

## 開発用：ローカルで起動する

ビルド・npm依存関係のインストールは不要です。Python 3などで静的HTTPサーバーを起動します。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開いてください。ES Modulesを使用しているため、HTMLファイルを直接開く方式には対応していません。
